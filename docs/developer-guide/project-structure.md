# Project structure

```text
studio/         Sanity Studio
frontend/       Nuxt site
docs/           these guides, imported into the Docs collection
package.json    workspace and scripts for npm, pnpm, yarn and bun
```

## Studio (`studio`)

```text
schemaTypes/
├─ documents/   page, collection, entry, author, settings
├─ objects/     link, seo, blockContent, table, pageBuilder, codeGroup, featureItem
├─ blocks/      one file per page-builder block
└─ shared/      field helpers (icon, image, orientation, code, languages)
presentation/   where each document appears on the site (Presentation tool)
scripts/
├─ seed.ts      example content
├─ docs.ts      Markdown guides → Docs collection
└─ lib/         Markdown → Portable Text converter, docs importer
structure.ts    the Studio menu
sanity.config.ts
```

## Site (`frontend`)

```text
app/
├─ pages/[...slug].vue      resolves every URL: page, collection or entry
├─ app.vue                  header, footer, languages, site-wide SEO
├─ components/
│  ├─ blocks/               Block*.vue, one per block
│  ├─ PageBlocks.vue        block registry
│  ├─ CollectionView.vue    collection list page
│  ├─ EntryList.vue         blog, cards, gallery and docs layouts
│  ├─ EntryView.vue         entry page (docs sidebar, TOC, related entries)
│  ├─ PortableText.vue      rich text renderer
│  ├─ CodeBlock.vue         code blocks with Shiki
│  ├─ LanguageSwitcher.vue  Nuxt UI LocaleSelect
│  ├─ SiteSearch.vue        search palette
│  └─ OgImage/              generated social image
├─ composables/             usePageSeo, useSanityImage, useSiteLanguage
├─ utils/                   queries.ts (GROQ), language, labels, links, toc
└─ assets/css/main.css      theme and motion utilities
modules/ui-locales.ts       lazy Nuxt UI locales
server/
├─ api/highlight.post.ts    syntax highlighting
├─ api/__sitemap__/urls.ts  sitemap entries from Sanity
└─ preview/                 preview routes that skip the Vercel cache
prerender-routes.ts         every URL, for hybrid and static builds
sanity.types.ts             generated by npm run typegen
nuxt.config.ts
```

## How a request is served

1. Every URL hits `app/pages/[...slug].vue`.
2. The language prefix, if any, is taken off the path (`/id/blog/post` → language `id`, path `blog/post`).
3. `ROUTE_QUERY` looks for a page, a collection and an entry matching the path in one request.
4. The page renders `PageBlocks`, `CollectionView` or `EntryView`; a miss is a 404.

Header, footer and settings come from `SETTINGS_QUERY` in `app.vue`, which runs before the page.
