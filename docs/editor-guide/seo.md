# SEO and sharing

Every page, collection and entry has an **SEO** tab. All its fields are optional: the site fills in sensible values from the content.

| Field | When empty |
| --- | --- |
| Meta title | The title of the document |
| Meta description | The excerpt or description, then the default description in Site Settings |
| Social share image | The cover image or first photo, then the default image in Site Settings, then an image generated from the title in the colors and fonts of the site |
| Hide from search engines | Off: the page is in the sitemap and can be found |

## Writing for search results

- Keep the **meta title** under about 60 characters, with the most important words first.
- Write the **meta description** as one or two sentences that make someone want to click, under about 155 characters.
- Give every page a different title and description.

## Hiding a page

Turn on **Hide from search engines** for pages such as a thank-you page or a draft campaign. The page stays reachable by its address, but search engines are asked not to list it, and it leaves the sitemap and the site search.

## Translations

Each translation has its own SEO tab, so titles and descriptions can be written for each language. Search engines are told which pages are translations of each other.
