# Blocks

Thirteen blocks come with the template. The homepage of the example site uses most of them, so it is a good place to see them in action.

## Hero

The large section at the top of a page: a title, a description, buttons and an optional image. With **Horizontal** orientation, the image sits next to the text. On the first block of a page, the title animates in when the page opens.

## Logo Cloud

A row of logos: clients, partners or the tools you use. Each logo is either an icon name (`i-simple-icons-vue`) or an uploaded image. Turn on **Scrolling marquee** to make the row move.

## Features Section

A heading followed by a list of features, each with an icon, a title and a short text. Add an image and choose **Horizontal** to show it next to the list.

## Card Grid

Cards in a grid, each with a title, a description, an icon or an image, and an optional link that makes the whole card clickable. **Spotlight** adds a light that follows the mouse; **Highlight** draws a colored border around a card.

## Timeline

Milestones, a history or the steps of a process. Each item has a free date or label ("March 2026", "Step 1"), a title, a description and an icon. Choose a vertical or horizontal layout.

## Image Gallery

A set of photos shown as a grid that opens a full-screen viewer, or as a slider. Drag several photos onto the field to upload them together, then add alternative text and captions.

## Rich Text

Free text with headings, lists, links, images, callouts and code. Use it for longer explanations on a page, such as terms or a story.

## Testimonials

Quotes from customers in columns. Each quote has a name, a role or company and an optional photo.

## FAQ

Questions and answers that open one at a time. Questions are numbered automatically.

## Pricing

Up to four plans side by side. Each plan has a name, a description, a price (with an optional crossed-out discount price), a billing period, a list of features, a button and an optional badge such as "Most popular". **Highlight** and **Scale** make one plan stand out.

## Call to Action

A highlighted box that asks visitors to do something: sign up, get in touch, read more. Add buttons and, if you like, an image.

## Callout

A short notice with an icon and optional buttons, for announcements or important information.

## Collection List

Shows entries from a collection and updates by itself when entries are published: the latest posts, recent projects, a few photo galleries. Choose the collection, how many entries to show, optionally a tag to filter by, and a "View all" button.

> [!TIP]
> **Same block, different look.** Most blocks have a color, a variant or an orientation. Try them in the Presentation view to see the result right away.
