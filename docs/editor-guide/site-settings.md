# Site Settings

**Site Settings** holds everything that appears on every page. Open it from the bottom of the Studio menu.

## General

| Field | What it does |
| --- | --- |
| Site name | Shown in the header, in the browser tab and as a large wordmark at the bottom of every page |
| Default description | Used by search engines when a page has no description of its own |
| Logo | Replaces the site name in the header. Optional |
| Default social share image | Shown when a link is shared and the page has no image. Optional: without it, the site generates an image from the page title |

## Header

- **Navigation**: the menu links. Each link points to a page, a collection, an entry or any address. Drag to reorder.
- **Header buttons**: up to two buttons on the right, such as *Contact*.
- **Search**: shows a search button in the header. Visitors can also press Ctrl + K (⌘ + K on a Mac).

## Footer

- **Footer columns**: up to four columns, each with a heading and links.
- **Footer text**: the small line at the bottom. Leave it empty to show "© year site name".
- **Social links**: a label, an address and an icon such as `i-simple-icons-instagram`, `i-simple-icons-x` or `i-simple-icons-linkedin`.

## Languages

Turns on more languages for the site. See [Translating content](./translating-content.md).

## Interface text

Words the site writes itself rather than you: "On this page", "Related posts", the message on an empty collection, the label of the language menu and the 404 page. Each field shows its default in grey. Fill a field only when you want different wording.

With several languages, each language has its own interface text.

> [!NOTE]
> **Some placeholders are filled in for you.** Text in curly brackets is replaced on the site: `{count} photos` shows "12 photos", `Related {entries}` shows "Related posts".
