# Introduction

Sanity × Nuxt UI is a website template built from blocks. Editors put pages together in **Sanity Studio**, a content editor that runs in the browser. The website, built with **Nuxt**, turns every block into a **Nuxt UI** component: a hero, a pricing table, a FAQ and so on.

The site you are reading is the example that comes with the template. Every page, menu and setting on it was made in the Studio, and these guides are no exception: they are a collection with the Docs layout.

## Who these guides are for

The guides come in two parts, so you can read only what you need.

- **Editor guide**: for the people who write and publish content. No code involved. It walks through the Studio, pages and blocks, collections, images, settings, languages and publishing.
- **Developer guide**: for the people who install, adapt and deploy the template. It covers installation, the content model, adding blocks, queries, theming, languages, Visual Editing, caching and hosting.

> [!TIP]
> **New to all of this?** Read [How it works](./how-it-works.md) first. It explains the handful of ideas everything else builds on, in plain words.

## What you get

- **13 blocks** that cover most marketing pages: hero, features, cards, timeline, gallery, rich text, testimonials, FAQ, pricing, call to action, callout, logo cloud and lists of entries.
- **Collections** that editors create themselves, such as a blog, a portfolio, a photo gallery or this documentation, each with its own list page.
- **A live preview** in the Studio: click any text on the page to edit it.
- **Several languages**, optional, switched on from the Studio.
- **Search**, **SEO** with generated social images, **responsive images** and **code blocks** with syntax highlighting.
- **Fast pages** that are cached, and hosting on Vercel, Cloudflare, any Node server or as static files.
